Tsuki Tunes Mobile es un reproductor de música con identidad visual **Cyberpunk & Anime**, sincronización en la nube mediante **Firebase**, catálogo y previsualizaciones a través de **Deezer API**, metadatos y etiquetas musicales de **Last.fm**, y reproducción completa mediante **Spotify Web API + Native SDK** con fallback automático.

## 1. Flujo de Autenticación y Acceso

### `LoginScreen` — `lib/screens/login_screen.dart`

La pantalla de inicio de sesión es la primera impresión del usuario y establece la identidad visual premium de la aplicación.

#### Estado Actual Implementado

* **Fondo Animado Cyberpunk con Renders en Tiempo Real:**
  * **Matriz Cyber Grid**: Cuadrícula sutil de tecnología en el fondo con micro-crucetas de orientación.
  * **Partículas Flotantes de Audio Embers**: 28 partículas de neón rojo carmesí (`#FF1919` y `#FF3344`) que ascienden suavemente con desvanecimiento senoidal continuo en los bordes (cero saltos de cuadro).
  * **Resplandor Plasmático Ambiental**: Nebulosa carmesí pulsante detrás del orbe central.
* **CyberOrb 3D Holográfico Central:**
  * Esfera de cristal 3D con plasma líquido carmesí interior, reflejos especulares de vidrio y máscara Tengu como holograma central.
  * **Ecualizador Radial de Audio 360°**: 48 barras de cápsula redondeada en formación circular simétrica alrededor de la esfera, con:
    * Latido rítmico de subwoofer en la órbita base.
    * Barras de doble frecuencia (primarias rítmicas + secundarias armónicas) con degradado de 4 tonos puramente rojo.
    * Micro-reflejos cilíndricos interiores y cinta de onda acústica de fondo fluida.
  * Anillos HUD externos desactivados para acabado limpio y minimalista.
* **Tipografía Cyberpunk con Efecto Glitch Aleatorio:**
  * Widget `CyberGlitchText` para textos "TSUKI" y "MUSICAL" con aberración cromática multi-capa en tonos rojos, corrupción de glifos y desplazamiento de franjas.
* **Barra de Telemetría HUD Superior en Vivo:**
  * Monitoreo real del servidor backend con LED indicador verde/rojo/amarillo parpadeante, latencia en milisegundos y versión de la app (`v1.0.0`).
* **Botón Cyberpunk "INGRESAR CON GOOGLE":**
  * Degradado carmesí a rubí oscuro con logotipo vectorial oficial de Google de 4 colores.
  * **Mascaritas Oni, Hannya y Tengu cayendo en color plomo oscuro** (`#2B2F38`): 8 siluetas en carriles simétricos (4 izquierda + 4 derecha), caída vertical recta con tiempos aleatorios y opacidad sutil tipo marca de agua (`0.14 - 0.18`).
  * **Brillo reflectante ultra-lento**: Shimmer cinematográfico cada 7.5 segundos con deslizamiento suave cosenoidal.
* **Pie de Página METAWORKS COMPANY:**
  * Shader de texto con gradiente armónico exclusivo entre **Rojo Carmesí (`#FF1919`)** y **Azul Eléctrico (`#00D4FF`)**, con beacons laterales sincronizados. Este es el único elemento de la pantalla que incluye tonos azules.
* **Inicio de Sesión con Google:**
  * Integración nativa con `google_sign_in` y Firebase Authentication.
  * Limpieza de sesión previa antes de abrir el selector de cuentas.
  * Sincronización segura de perfil con Firestore (aislada con `try-catch` para evitar bloqueos por reglas de seguridad o problemas de red).
  * Manejo inteligente de cancelación voluntaria (sin mostrar SnackBar de error si el usuario simplemente cierra el diálogo).

### 4.3 Doble Motor de Audio
**Archivo:** `lib/providers/audio_provider.dart`

| Característica | Spotify Web API + Native SDK | Deezer API Preview |
|:---|:---|:---|
| **Fuente** | Conexión a cliente Spotify y/o Web API | Streams oficiales de Deezer |
| **Duración** | Canción completa (*Full track*) | Muestra de alta fidelidad (30 seg) |
| **Requisito** | Cuenta Spotify vinculada con PKCE OAuth | Ninguno (abierto por defecto) |
| **Fallback** | Si falla la conexión Spotify, conmuta automáticamente al preview de Deezer sin interrumpir la experiencia | — |
| **Resiliencia** | Token refresh resistente a microcortes de red; solo revoca en `invalid_grant` explícito | — |
| **Diagnóstico** | `lastError`, detección de dispositivo activo (`activeDeviceName`), lanzador directo de app Spotify | — |

| **AudioPlayerService** | `lib/services/audio_player_service.dart` | Servicio de bajo nivel para reproducción de previews de Deezer con `just_audio`. |
